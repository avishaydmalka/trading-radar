## חלופה: שרת משלך (Oracle Cloud Always Free + Docker)

השרת החינמי של Oracle (ARM, עד 4 ליבות ו‑24GB) פועל ללא הגבלת זמן ולא נכבה, ולכן מתאים למערכת שסורקת כל 5 דקות.

1. **יצירת שרת:** פתחו חשבון ב‑cloud.oracle.com ← Compute ← Create Instance.
   - בחרו Ubuntu 24.04 ותבנית Ampere (A1).
   - ב‑Security List של ה‑VCN פתחו את פורטים 80 ו‑443.
2. **דומיין חינמי:** ב‑duckdns.org צרו למשל `myradar.duckdns.org` והפנו אותו לכתובת ה‑IP של השרת.
3. **התקנה על השרת:**
   ```bash
   sudo apt update && sudo apt install -y docker.io docker-compose-v2 unzip
   sudo iptables -I INPUT -p tcp -m multiport --dports 80,443 -j ACCEPT   # בתמונות של Oracle
   unzip trading-radar.zip && cd trading-radar
   cp .env.example .env && nano .env       # DOMAIN, DASHBOARD_PASSWORD, מפתחות
   sudo docker compose up -d --build
   ```
4. גלשו ל‑`https://myradar.duckdns.org`. האישור (SSL) מונפק אוטומטית על ידי Caddy.

**חלופות:**
- Google Cloud e2‑micro (חינמי באזורי ארה״ב).
- כל VPS זול.
- הרצה מקומית ב‑Docker לצד Cloudflare Tunnel.

**עדכון גרסה:**
```bash
sudo docker compose up -d --build
```
הנתונים שמורים בתיקייה `data/`.

## חיבור ההתראות

### טלגרם (2 דקות)
1. בטלגרם, פתחו את ‎@BotFather ושלחו `/newbot`. העתיקו את הטוקן ל‑`TELEGRAM_BOT_TOKEN`.
2. הפעילו מחדש:
   ```bash
   docker compose restart radar
   ```
3. שלחו לבוט שלכם `/start`. הוא יחזיר את ה‑chat id שלכם. הכניסו אותו ל‑`TELEGRAM_CHAT_ID` והפעילו מחדש שוב.

**פקודות בבוט:**
- `/portfolio` – מצב התיק
- `/top` – הזדמנויות
- `/stock NVDA` – ניתוח מניה
- `/brief` – תדריך שוק
- `/alerts` – התראות אחרונות
- `/scan` – סריקה עכשיו

הבוט עונה רק ל‑chat id שהוגדר.

### התראות לטלפון ולדפדפן (Push)
1. צרו מפתחות והעתיקו את שתי השורות ל‑`.env`:
   ```bash
   docker compose exec radar python -m app.tools.gen_vapid
   ```
2. הפעילו מחדש, ובדשבורד: ⚙️ ← התראות ← **הפעל**.
3. **באייפון:** קודם "הוסף למסך הבית" ב‑Safari, ורק אחר כך הפעילו התראות מתוך האפליקציה שנוספה.

### מודלי AI חינמיים
- **Gemini:** מפתח מ‑aistudio.google.com/apikey. מודל ברירת המחדל הוא `gemini-flash-latest` (alias שמתעדכן לבד).
- **Groq:** מפתח מ‑console.groq.com/keys. מהיר מאוד.
- **OpenRouter:** מודלים עם הסיומת `:free`.
- **Ollama:** מודל מקומי, ללא מגבלות. מתאים לשרת ARM של Oracle עם RAM גדול.

המערכת מנסה את הספקים לפי הסדר שב‑`LLM_PROVIDERS`. כשספק מחזיר 429 (חריגה ממכסה), היא מדלגת לבא אחריו. כברירת מחדל יש עד 4 קריאות AI בכל סריקה, וכל מניה מנותחת מחדש פעם ב‑30 דקות או מיד כשמופיע איתות חזק חדש, כדי להישאר בתוך המכסות החינמיות.

> שימו לב: בשכבות החינמיות, הספקים רשאים להשתמש בטקסט שנשלח אליהם לשיפור המודלים. המערכת שולחת סימולים, אינדיקטורים וכותרות, אבל גם את הכמויות ומחירי הקנייה שלכם. אם זה מפריע לכם, השתמשו ב‑Ollama מקומי.

- **ניהול התיק:** הוספה ועריכה של פוזיציות, סלים, סטופ, יעד וסטופ נגרר דרך ⚙️ ← "תיק ומעקב", או בלחיצה על מניה.

- **ניתוח מלא עכשיו:** ⚙️ ← מערכת ← "סריקה + ניתוח AI מלא".
- **הוספת מקורות:** `config/portfolio.yaml` ← `feeds`.

**שעות סריקה:**
- כשהמסחר בארה״ב או בת״א פתוח: כל 5 דקות.
- במסחר מורחב בארה״ב: כל 15 דקות.
- כשהכל סגור: פעם בשעה.
